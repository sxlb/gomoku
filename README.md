# Typecho Handsome 五子棋插件

一个功能完善、界面优美的五子棋游戏页面模板，专为 Typecho 的 Handsome 主题设计。

## ✨ 特性

### 🎮 游戏功能
- **双人对战** - 支持玩家之间的对弈
- **人机对战** - 智能 AI 对手，3个难度等级
- **悔棋功能** - 支持悔棋操作
- **提示系统** - 提供最佳落子位置建议
- **游戏回放** - 完整的棋局回放功能
- **战绩统计** - 记录胜场、败场和连胜记录
- **历史记录** - 保存最近游戏记录

### 🎨 界面功能
- **多主题支持** - 4种棋盘主题可选
  - 经典木纹
  - 现代简约
  - 暗夜模式
  - 清新绿色
- **响应式设计** - 完美适配移动端和桌面端
- **精美动画** - 棋子落子动画和胜负高亮
- **计时模式** - 支持30秒/60秒每步的限时模式

### 🔊 音效系统
- 落子音效
- 胜利/失败音效
- 音量控制

### ⌨️ 快捷键支持
- 方向键移动光标
- 回车键落子

## 🚀 安装

### 1. 上传文件
将 `page_gomoku.php` 文件上传到您的 Typecho 博客目录：
```
/usr/themes/handsome/page_gomoku.php
```

### 2. 创建页面
1. 登录 Typecho 后台
2. 进入「管理」→「独立页面」
3. 点击「新增」
4. 在「自定义模板」中选择「五子棋游戏」
5. 填写页面标题（如「五子棋」）
6. 点击「发布」

## 🎯 使用说明

### 游戏设置
- **游戏模式** - 选择「双人对战」或「人机对战」
- **玩家执棋** - 在人机模式下选择黑方或白方
- **AI难度** - 选择简单、中等或困难
- **计时模式** - 关闭或选择限时模式
- **棋盘主题** - 选择喜欢的视觉风格

### 游戏操作
- **落子** - 点击棋盘空白处
- **提示** - 点击「💡 提示」按钮获取建议
- **悔棋** - 点击「↩️ 悔棋」撤销上一步
- **重开** - 点击「🔄 重开」开始新游戏
- **回放** - 点击「📹 回放」查看棋局

## 🛠️ 技术实现

### AI算法
- 使用 Minimax 算法配合 Alpha-Beta 剪枝
- 基于位置评估函数的评分系统
- 候选位置筛选优化性能
- 支持3个难度级别的配置

### 存储
- 使用 localStorage 保存战绩和历史记录
- 数据持久化存储在浏览器端

### 音效
- 基于 Web Audio API 生成音效
- 无需外部音频文件
