# Typecho Handsome 五子棋插件

> 一个功能完善、界面优美的五子棋游戏页面模板，专为 Typecho 的 Handsome 主题设计。

## ✨ 特性

### 🎮 游戏玩法
- **双人对战** — 本地双人对弈
- **人机对战** — 智能 AI 对手，3 个难度等级
- **禁手规则** — 专业五子棋规则（三三禁手、四四禁手、长连禁手，仅黑方受限制）
- **自由模式** — 游戏结束后仍可悔棋和使用提示，适合复盘练习
- **限时赛** — 每方总时间 5 分钟的限时对弈
- **悔棋功能** — 支持撤销落子
- **AI 提示** — 推荐最佳落子位置
- **游戏回放** — 完整回放，支持前进/后退/自动播放/进度拖拽
- **战绩统计** — 胜场、败场、平局、连胜记录
- **历史记录** — 自动保存最近对局，可加载回放

### 🎨 界面设计
- **4 种棋盘主题** — 经典木纹、现代简约、暗夜模式、清新绿色
- **响应式布局** — 完美适配移动端和桌面端
- **精美动画** — 落子动画、胜利高亮、禁手警告脉冲
- **渐进式状态显示** — 实时状态栏、计时器、音效开关

### 🔊 音效系统
- 落子音效
- 胜利 / 失败音效
- 音量开关
- 基于 Web Audio API，无需外部音频文件

### ⌨️ 键盘快捷键
| 按键 | 功能 |
|------|------|
| 方向键 | 移动光标 |
| 回车 / 空格 | 落子 |
| `H` | 提示 |
| `U` | 悔棋 |
| `R` | 重开 |

## 🚀 快速开始

### 环境要求
- Typecho 1.2+
- Handsome 主题 8.0+
- 现代浏览器（支持 ES6）

### 安装步骤

1. **上传文件**

   将 `page_gomoku.php` 上传到 Handsome 主题目录：
   ```
   /usr/themes/handsome/page_gomoku.php
   ```

2. **创建页面**

   - 登录 Typecho 后台
   - 进入「管理」→「独立页面」→「新增」
   - 在「自定义模板」中选择「五子棋游戏」
   - 填写页面标题（如「五子棋」），发布即可

## 🎯 使用指南

### 设置项说明

| 设置项 | 选项 | 说明 |
|--------|------|------|
| 游戏类型 | 标准 / 自由 | 自由模式允许游戏结束后继续悔棋和提示 |
| 游戏模式 | 双人对战 / 人机对战 | 选择 PvP 或 PvE |
| 玩家执棋 | 黑方 / 白方 | 人机模式下选择先手还是后手 |
| AI 难度 | 简单 / 中等 / 困难 | 搜索深度和候选数不同 |
| 禁手规则 | 关闭 / 开启 | 开启后黑方受三三、四四、长连禁手限制 |
| 计时模式 | 关闭 / 30秒 / 60秒 / 限时赛 | 每步计时或总时制 |
| 棋盘主题 | 木纹 / 现代 / 暗夜 / 绿色 | 切换视觉风格 |

### 操作方式

- **落子** — 点击棋盘空白处，或使用方向键 + 回车键
- **悔棋** — 点击「↩️ 悔棋」按钮或按 `U`
- **提示** — 点击「💡 提示」按钮或按 `H`
- **重开** — 点击「🔄 重开」按钮或按 `R`
- **回放** — 游戏结束后点击「📹 回放」
- **历史** — 点击「📜 历史」查看最近对局

## 🛠️ 技术架构

### 模块设计

代码采用模块化 IIFE 模式，职责清晰，便于维护和扩展：

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  CONSTANTS  │  │    Utils    │  │    Sound    │
│  (常量模块) │  │  (工具函数)  │  │  (音效模块)  │
└─────────────┘  └─────────────┘  └─────────────┘
        │               │                │
┌───────┴───────────────┴────────────────┴───────┐
│                       AI                       │
│              (AI 搜索与评估模块)                │
└───────────────────────┬───────────────────────┘
┌───────────────────────┴───────────────────────┐
│                     Game                       │
│              (游戏状态与核心逻辑)                │
└───────┬───────────────┬───────────────┬───────┘
        │               │               │
┌───────┴───┐  ┌────────┴──────┐  ┌────┴───────┐
│    UI     │  │    Timer      │  │   Replay   │
│ (UI渲染)  │  │  (计时器模块)  │  │ (回放模块)  │
└───────────┘  └───────────────┘  └────────────┘
┌───────────┐  ┌───────────────┐  ┌────────────┐
│  History  │  │     Stats     │  │ Controller │
│ (历史记录) │  │  (统计模块)    │  │ (主控制器)  │
└───────────┘  └───────────────┘  └────────────┘
```

### 模块清单

| 模块 | 主要职责 |
|------|----------|
| **Constants** | 棋盘尺寸、方向向量、评分模式、难度配置等常量 |
| **Utils** | 边界检测、对手转换、玩家名称、结果标签等通用方法 |
| **Sound** | 基于 Web Audio API 的音效生成与播放控制 |
| **AI** | Minimax + Alpha-Beta 剪枝、棋型评估、候选点筛选 |
| **Game** | 棋盘状态、落子/悔棋、胜负判定、禁手检测 |
| **UI** | DOM 构建与更新、事件绑定、状态渲染 |
| **History** | 对局历史的本地存储与读取 |
| **Stats** | 战绩统计（胜/负/平/连胜） |
| **Timer** | 多种计时模式（每步计时 / 总时制） |
| **Replay** | 棋局回放控制（前进/后退/自动播放/进度条） |
| **Controller** | 主控制器，协调各模块交互 |

### AI 算法

- **搜索算法** — Minimax + Alpha-Beta 剪枝
- **评估函数** — 基于棋型模式匹配（五连 / 活四 / 冲四 / 活三 / 眠三等）
- **候选筛选** — 只考虑已有棋子周围 2 格内的空位，大幅减少搜索空间
- **难度配置**：
  | 难度 | 搜索深度 | 顶层候选数 | 内部候选数 |
  |------|----------|------------|------------|
  | 简单 | 1 | 8 | 6 |
  | 中等 | 2 | 12 | 8 |
  | 困难 | 3 | 15 | 10 |

### 数据存储

- **存储方式** — 浏览器 localStorage
- **存储键**：
  - `gomokuStats` — 战绩统计
  - `gomokuHistory` — 历史记录（最多 10 条）
